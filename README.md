# S'N'G · Crea il tuo pantalone (versione offline)

Versione solo visualizzazione del configuratore Silk'n'Grit, installabile sul telefono/iPad ("Aggiungi a Home") e funzionante senza internet.
Pubblicata con GitHub Pages. I file sono generati da `build.py` (nei file del progetto, cartella configuratore/offline/strumenti) a partire dalla pagina del negozio.
